How it works

Three steps. No signup.

1. Install

Add PageChat in Chrome, then pin it. Click the icon or press Alt+Y to open the side panel.

2. Open a page

Stay on the tab you care about. Check Include this page only when you want the model to read it.

3. Ask or summarize

Chat, summarize the site, extract company info, or translate the selection from the right-click menu.

Questions

Do I need my own API key?

No. PageChat is ready to use after install. The model key stays on our server, not in the extension.

Is page content always sent?

No. Default chat does not include the tab. Content is sent only when you check Include this page, summarize the site, extract company info, or send a selection from the right-click menu.

Which pages can it read?

Most public http(s) pages. Chrome Web Store, extension pages, some PDFs, and chrome:// URLs cannot be read. Pages behind login, and URLs the site does not link to, are not crawled.

Is it free?

Yes. There is no subscription wall in the extension.
