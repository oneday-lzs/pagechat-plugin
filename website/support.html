Support

PageChat is a Chrome side-panel assistant for summarizing pages and sites. Use this page if install fails, a page cannot be read, or you want to report a problem.

Install

Source and issues live on GitHub. After you load the extension, click the toolbar icon or press Alt+Y.

You do not add an API key. If chat replies with a temporary unavailability message, wait and try again, or email us.

Pages it cannot read

Chrome Web Store, other extension pages, some PDFs, and chrome:// URLs are blocked by the browser. Site summary only follows public links on the same hostname. Content behind login is not crawled.

Privacy

Chats stay in local Chrome storage. Page text is sent to the hosted model only when you include the page, summarize the site, extract company info, or use a context-menu action. See the privacy policy.
